# SGPA Calculator - Python 🧮

This is a simple command-line Python script that allows you to calculate your **SGPA (Semester Grade Point Average)** manually by entering:
- Subject names
- Subject codes
- Credits
- Internal and external marks

It then computes:
- Total marks
- Grade points
- Credit points
- Final SGPA for the semester

## 📌 Features

- Manual entry for subjects, marks, and credits
- Grade point logic based on total marks
- Automatic SGPA calculation
- Easy-to-use CLI interface

## 🎯 Grade Point Criteria

| Total Marks | Grade Point |
|-------------|--------------|
| 90+         | 10           |
| 80–89       | 9            |
| 70–79       | 8            |
| 60–69       | 7            |
| 50–59       | 6            |
| 40–49       | 5            |
| < 40        | 0 (Fail)     |

## 🛠 How to Run

```bash
git clone https://github.com/your-username/SGPA-Calculator-Python.git
cd SGPA-Calculator-Python
python sgpa_calculator.py
```
